Guitar FEM + STK Project — Working Summary

1) Vision / Goal
Build a software tool that lets a user “design” a guitar (shape, dimensions, materials) and then:

3D Geometry & Meshing: Generate a parametric 3D model with a soundhole using Gmsh.

Numerical Physics (FEM): Estimate physical behavior (natural frequencies/modes) using 3D Elasticity equations.

Audio Synthesis (STK): Generate synthetic sound reflecting the 3D body characteristics.

Interactive UI: A real-time Streamlit dashboard to control dimensions and trigger the pipeline.

Pipeline:
User Input (GUI) → JSON Config → 3D Mesh (Gmsh) → 3D FEM (Python/Sfepy) → Modal Results (JSON) → C++ STK → WAV Audio.

2) Environment / Setup
VM: Ubuntu (VirtualBox), user: vboxuser, path: ~/final-project.

Venv: .venv (Sfepy, Gmsh, Streamlit, Numpy, Scipy).

Gmsh: Installed as a Python library and standalone engine for 3D meshing.

Audio: WAV exports to Shared Folder recommended due to VM stuttering.

4) FEM Side (3D Evolution) — Current Status
3D Orthotropic Modeling: Transitioned from 2D plates to 3D volumes. Implementation of the 6x6 Stiffness Matrix (C-matrix) derived from 9 engineering constants (
E,ν,G
) for wood.

Geometry Engine (Gmsh): Successfully integrated a parametric 3D "Box" model with:

Adjustable Length, Width, and Depth.

Dynamic Wall Thickness (Hollow Shell).

Circular Soundhole on the top plate.

Physics Status: The pipeline is currently using a Mock Solver (Placeholder) for natural frequencies while waiting for the finalized 3D Structural-Acoustic equations (ASI) from the analytic research.

5) STK Side (C++) — Current Status
Musical pitch defines the base frequency; FEM modes provide timbre coloration.

Integration Ready: The GUI is prepared to call the compiled ./guitar_stk binary using the 3D JSON output.
